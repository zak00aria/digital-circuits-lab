# Digital Circuits Lab

A collection of digital logic circuits designed and simulated using [CircuitVerse](https://circuitverse.org/).

This repository contains small experiments and larger digital circuit projects covering combinational logic, sequential logic, counters, registers, decoders, arithmetic circuits, and display systems.

You can view all of the projects on my CircuitVerse [dashboard](https://circuitverse.org/users/25835).

## Projects

| Project | Description |
|---------|-------------|
| [7-Segment Display Decoder](./7-segment-decoder/) | A BCD-to-7-segment display decoder |
| [Two-Digit BCD Counter](./Tow-Digits-Counter/) | A configurable BCD counter built using JK flip-flops |
| [24-Hour Digital Clock](./24-Hour-Digital-Clock/) | A clock displaying hours, minutes, and seconds in 24-hour format |
| [8-Bit Bidirectional Shift Register](./8-bit-Bidirectional-Shift-Register/) | An 8-bit register that shifts left or right with a selectable shift-in bit |
| [8-Bit ALU](./8-bit-ALU/) | An ALU supporting arithmetic, logic, and shift operations |
| [Infinite Tic-Tac-Toe Game](./Infinite-Tic-Tac-Toe/) | A two-player game using a `24 x 24` pixel matrix |
